Part A: Detailed Guide

1. How C Works

C is a compiled, procedural, low-level language. Source code goes through four stages: preprocessing (#include, #define), compilation (to assembly), assembly (to an object file), and linking (to an executable).

#include <stdio.h>
int main(void) {
    printf("Hello, C\n");
    return 0;
}

Compile with gcc -Wall -Wextra -g main.c -o main. Always turn warnings on and take them seriously.

2. Data Types and Operators

  • Integers: char, short, int, long, long long, each signed or unsigned. Use <stdint.h> (int32_t, uint8_t) when exact size matters.
  • Floating point: float, double. Never compare with ==; compare with a small tolerance.
  • Sizes are implementation-defined. Typical 64-bit: char 1, short 2, int 4, long 8 (Linux/macOS), float 4, double 8, pointer 8. Use sizeof.
  • Integer promotion: char and short are promoted to int in expressions. Mixing signed and unsigned converts the signed value to unsigned, a classic bug (-1 < 1u is false).
  • Signed overflow is undefined behavior. Unsigned overflow wraps around.
  • Integer division truncates toward zero. % takes the sign of the left operand.
  • && and || short-circuit. Mixing up = and == is a frequent mistake.
  • Precedence trap: a & b == c parses as a & (b == c). Use parentheses.

3. Control Flow

if/else, switch (needs break or it falls through; case labels must be integer constants), for, while, do-while, break, continue, and goto (rare, mostly for cleanup in error paths).

4. Functions

  • C is always pass by value. To modify the caller's variable, pass a pointer.
  • Declare prototypes in headers; define functions in .c files.
  • Arrays decay to pointers when passed, so also pass the length.
  • Recursion uses the stack; each call has a stack frame. Very deep recursion causes stack overflow.
  • Use int main(void) or int main(int argc, char *argv[]). Never void main().
  • Variadic functions (like printf) use <stdarg.h>: va_list, va_start, va_arg, va_end.

5. Arrays and Strings

int a[5] = {1, 2, 3};      // remaining elements are zero
int b[] = {1, 2, 3, 4};    // size deduced as 4
char s1[] = "hello";       // modifiable copy, 6 bytes
char *s2 = "hello";        // points to read-only literal
  • A string is a char array ending with '\0'.
  • sizeof(arr) gives total bytes only where arr is a real array, not a function parameter.
  • Out-of-bounds access is undefined behavior; C does no bounds checking.
  • Key functions: strlen, strcmp, strcpy, strncpy, strcat, strstr, strchr, memcpy, memmove, memset. Use memmove if regions overlap.
  • strncpy does not always null-terminate. Prefer snprintf for safe formatting.
  • Never use gets(). Use fgets().
  • 2D arrays are stored row-major: int m[3][4] is 12 contiguous ints.

6. Pointers (the Heart of C)

A pointer stores a memory address.

int x = 10;
int *p = &x;     // p holds the address of x
*p = 20;         // x is now 20
int **pp = &p;   // pointer to pointer

Key rules

  • Pointer arithmetic scales by element size: p + 1 advances by sizeof(*p) bytes.
  • a[i] is exactly *(a + i).
  • An array name is not a pointer, but it decays to one in most expressions (exceptions: sizeof and &).
  • void * is a generic pointer; you cannot dereference it or do arithmetic on it directly.
  • Dereferencing NULL crashes (segmentation fault). Always check the return of malloc and fopen.
  • Pointer subtraction gives the element count between two pointers (type ptrdiff_t).

const with pointers (read right to left)

  • const int *p: value is read-only, pointer can move.
  • int *const p: pointer is fixed, value can change.
  • const int *const p: both fixed.

Pointer expressions interviewers love

  • *p++: use the value, then increment the pointer.
  • (*p)++: increment the value.
  • *++p: increment the pointer, then use the value.
  • ++*p: increment the value, then use it.

Pointer to array vs array of pointers: int (*p)[5] is a pointer to an array of 5 ints; int *p[5] is an array of 5 int pointers.

7. Dynamic Memory

int *p = malloc(n * sizeof *p);
if (p == NULL) { /* handle failure */ }
int *q = realloc(p, 2 * n * sizeof *p);
if (q == NULL) { free(p); /* handle failure */ }
else p = q;
free(p);
p = NULL;
  • malloc returns uninitialized memory. calloc(n, size) zero-initializes.
  • realloc may move the block, so assign its result to a temporary first.
  • Every malloc needs exactly one free.
  • Memory bugs: leak (never freed), dangling pointer (use after free), double free, buffer overflow, uninitialized read, wild pointer (never initialized).
  • Never return a pointer to a local variable; it lives on the stack and dies when the function returns.
  • Stack: automatic, fast, limited size, holds locals. Heap: manual, larger, slower, persists until freed. Also: data segment (initialized globals), BSS (uninitialized globals, zeroed), text segment (code).

8. Structs, Unions, Enums, typedef

typedef struct {
    int id;
    char name[32];
} Student;
Student s = { .id = 1, .name = "Asha" };
Student *ps = &s;
ps->id = 2;          // same as (*ps).id
  • Structs are copied by value on assignment and when passed to functions.
  • Padding: the compiler inserts bytes so members align. sizeof a struct can exceed the sum of its members. Order members from largest to smallest to reduce size. Use offsetof to inspect.
  • A union shares one memory block among its members; its size equals the largest member. Reading a member other than the one last written reinterprets the bytes: allowed in C, but the result is machine dependent and may be a trap value.
  • enum constants are integers starting at 0.
  • Bit-fields (unsigned flag : 1;) pack bits, but their layout is implementation-defined.
  • Flexible array member: struct { int n; int data[]; } allocated with malloc(sizeof(struct) + n * sizeof(int)).

9. Storage Classes and Qualifiers

  • auto: default for locals.
  • static local: initialized once, keeps its value across calls, lives in the data segment.
  • static global or function: visible only inside that file (internal linkage).
  • extern: declares a variable or function defined in another file.
  • register: a hint, mostly ignored; you cannot take its address.
  • const: read-only. In C, a const variable is not a compile-time constant.
  • volatile: the value may change unexpectedly (hardware registers, interrupt handlers), so the compiler must not optimize reads away. It does not give thread safety.
  • restrict: a promise that a pointer is the only access to that memory, enabling optimizations.
  • inline: a suggestion to inline a function.

10. Preprocessor

#define PI 3.14159
#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))
#ifndef MYHEADER_H
#define MYHEADER_H
/* declarations */
#endif
  • Macros are text substitution with no type checking. SQUARE(i++) evaluates i++ twice (bug). Always parenthesize arguments and the whole body.
  • # stringifies an argument; ## pastes tokens.
  • Include guards (or #pragma once) prevent double inclusion.
  • #include <file> searches system paths; #include "file" searches the local directory first.
  • Conditional compilation: #if, #ifdef, #else, #endif. Predefined: __FILE__, __LINE__, __func__.
  • Prefer const and enum over macros for constants, and static inline over function-like macros.

11. File I/O

FILE *f = fopen("data.txt", "r");
if (!f) { perror("fopen"); return 1; }
char line[256];
while (fgets(line, sizeof line, f)) {
    printf("%s", line);
}
fclose(f);
  • Modes: r, w (truncates), a (append), r+, w+, a+; add b for binary.
  • Functions: fprintf, fscanf, fgets, fputs, fread, fwrite, fseek, ftell, rewind, feof, fflush.
  • Do not loop on while (!feof(f)); check the return value of the read instead.
  • stdin, stdout, stderr are always open. stdout is buffered; stderr is not.
  • scanf returns the number of items read; always check it. %s without a width can overflow, so use %31s.

12. Bitwise Operations

x & (1u << n)       // test bit n
x |= (1u << n);     // set bit n
x &= ~(1u << n);    // clear bit n
x ^= (1u << n);     // toggle bit n
x & (x - 1)         // clear lowest set bit
x & -x              // isolate lowest set bit
(x & (x - 1)) == 0  // power of two (x > 0)
  • Count set bits: loop with x &= x - 1 (Brian Kernighan's method).
  • Right shift of negative signed values is implementation-defined; shifting by the width or more is undefined.
  • Swap without a temp: a ^= b; b ^= a; a ^= b; (fails if both refer to the same variable).
  • Endianness check: int n = 1; *(char *)&n == 1 means little endian.

13. Function Pointers and Callbacks

int add(int a, int b) { return a + b; }
int (*op)(int, int) = add;
int r = op(2, 3);
qsort(arr, n, sizeof arr[0], cmp);   // cmp is a callback

Uses: callbacks, dispatch tables, simple polymorphism, plugin-style design.

14. Undefined Behavior

  • Undefined: out-of-bounds access, null dereference, signed overflow, use after free, modifying a string literal, unsequenced modification (i = i++ + ++i), reading uninitialized variables, using the value of a non-void function that lacks a return.
  • Unspecified: order of evaluation of function arguments.
  • Implementation-defined: size of int, signedness of plain char, struct padding.
  • With undefined behavior anything can happen, including appearing to work.

15. Data Structures to Implement

Do each of these at least once, with full memory management:

  • Dynamic array (vector) with resize
  • Singly and doubly linked list (insert, delete, reverse, find middle, detect cycle)
  • Stack and queue (array and linked-list versions)
  • Circular buffer
  • Hash table with chaining
  • Binary search tree (insert, search, delete, traversals)
  • Min-heap / priority queue
  • String library: strlen, strcpy, strcmp, strstr, atoi, itoa, memcpy, memmove

16. Interview Questions with Answers

Difference between malloc and calloc? calloc takes count and size and zeroes the memory; malloc takes total bytes and leaves it uninitialized.

What is a dangling pointer? A pointer to memory that has been freed or gone out of scope. Fix: set it to NULL after free; never return addresses of locals.

What is a memory leak? Heap memory that was allocated but never freed and is no longer reachable.

Stack vs heap? Stack is automatic, fast, small, with LIFO frames. Heap is manual, flexible, larger, and can fragment.

What does static do? Local: persists between calls. Global or function: limits visibility to the file.

const vs #define? const has a type and scope and shows in the debugger; #define is untyped text replacement.

Array vs pointer? An array is a block of storage; a pointer is a variable holding an address. Arrays decay to pointers, but sizeof and & treat them differently.

Why is a write to a string literal a bug? char *s = "abc"; s[0] = 'x'; modifies a string literal, which is undefined behavior. Use char s[] = "abc"; instead.

What is void pointer? A generic pointer; it must be cast before dereferencing. malloc returns it.

struct vs union? Struct members have separate storage; union members overlap in the same memory.

What is a segmentation fault? Access to memory the process may not touch: null or wild pointers, stack overflow, writing read-only memory.

What is volatile for? It stops the compiler from caching or optimizing away reads of a variable that can change outside normal program flow.

i++ vs ++i? Both increment; the value of the expression differs (old value vs new value).

Common macro pitfalls? Double evaluation of arguments and missing parentheses.

When is sizeof evaluated? At compile time (except for variable-length arrays).

How do you avoid buffer overflow? Check lengths, use fgets, snprintf, and strncpy with explicit termination, and validate all input sizes.

What is memory alignment? Hardware prefers data at addresses that are multiples of its size; compilers pad structs for this.

What if you free the same pointer twice? Undefined behavior; usually heap corruption or a crash.

memcpy vs memmove? memmove handles overlapping regions correctly; memcpy does not.

What is a reentrant function? One that is safe to call again before a previous call finishes (no static or global state). Required for interrupt handlers and threads.

What is the difference between a macro and an inline function? A macro is expanded by the preprocessor with no type checking; an inline function is type-checked and evaluates its arguments once.

What is a null pointer vs an uninitialized pointer? A null pointer deliberately points to nothing and can be tested. An uninitialized pointer holds a garbage address and cannot be tested safely.

What are the different memory segments of a C program? Text (code), initialized data, BSS (zero-initialized data), heap, and stack.

What does extern do? It declares that a variable or function is defined in another translation unit, without allocating storage.

17. Classic Coding Problems

  • Reverse a string in place; check for palindrome
  • Reverse a linked list (iterative and recursive); find the middle; detect and remove a loop (Floyd)
  • Merge two sorted lists
  • Find the missing number; find duplicates
  • Count set bits; reverse bits; check power of two
  • Swap two variables without a temp
  • Implement atoi and itoa with edge cases (sign, overflow, whitespace)
  • Binary search; bubble, insertion, quick and merge sort
  • Fibonacci and factorial (recursive and iterative)
  • Matrix transpose and rotate
  • Implement memcpy and handle overlap in memmove
  • Check endianness
  • Remove duplicates from a sorted array
  • Balanced parentheses using a stack
  • Implement a circular queue or simple LRU cache

18. Debugging and Tooling

  • gcc -Wall -Wextra -Wpedantic -g -fsanitize=address,undefined catches most memory and undefined-behavior bugs early.
  • valgrind ./prog finds leaks and invalid reads and writes.
  • gdb ./prog: break, run, next, step, print, backtrace, watch.
  • make for builds; clang-format and cppcheck for style and static checks.

19. How to Study Effectively

  • Type every example yourself; do not just read.
  • Draw memory diagrams (stack, heap, pointer arrows) for every pointer problem.
  • After each topic, write a small program that uses it, then deliberately break it and read the error.
  • Solve 2 to 3 problems a day on HackerRank or LeetCode in C only.
  • Explain concepts aloud as if answering an interviewer.
  • Read good code: the Linux kernel list implementation, SQLite, or Redis source.

Recommended books: The C Programming Language (Kernighan and Ritchie); C Programming: A Modern Approach (K. N. King); Expert C Programming: Deep C Secrets (van der Linden); Understanding and Using C Pointers (Reese).

Free resources: Beej's Guide to C, Harvard CS50, Exercism C track.

B6. Bit Manipulation Tricks

x & (1u << n)          // test bit n
x |  (1u << n)         // set bit n
x & ~(1u << n)         // clear bit n
x ^  (1u << n)         // toggle bit n
x & (x - 1)            // clear lowest set bit
x & -x                 // isolate lowest set bit
(x & (x - 1)) == 0     // power of two (x > 0)
x << k                 // multiply by 2^k
x >> k                 // divide by 2^k (unsigned)
(x >> n) & 1u          // extract bit n
(x >> p) & ((1u << w) - 1)   // extract w bits starting at bit p
// Count set bits (Kernighan)
int count = 0;
while (x) { x &= x - 1; count++; }

B7. Must-Know Code Snippets

Swap using a temporary and using a pointer

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

String length and string copy

size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p) p++;
    return p - s;
}
char *my_strcpy(char *d, const char *s) {
    char *r = d;
    while ((*d++ = *s++)) ;
    return r;
}

Reverse a string in place

void reverse(char *s) {
    int i = 0, j = strlen(s) - 1;
    while (i < j) {
        char t = s[i];
        s[i++] = s[j];
        s[j--] = t;
    }
}

Linked list node and reverse

struct Node { int data; struct Node *next; };
struct Node *reverse_list(struct Node *head) {
    struct Node *prev = NULL, *cur = head;
    while (cur) {
        struct Node *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

Detect a cycle (Floyd)

int has_cycle(struct Node *head) {
    struct Node *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return 1;
    }
    return 0;
}

atoi with sign handling

int my_atoi(const char *s) {
    int sign = 1, n = 0;
    while (*s == ' ') s++;
    if (*s == '-') { sign = -1; s++; }
    else if (*s == '+') s++;
    while (*s >= '0' && *s <= '9')
        n = n * 10 + (*s++ - '0');
    return sign * n;
}

Endianness check

int n = 1;
puts(*(char *)&n ? "little endian" : "big endian");

Function pointer and qsort comparator

int cmp(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);   // avoids overflow of x - y
}
qsort(arr, n, sizeof arr[0], cmp);

B8. Top Gotchas and Undefined Behavior

Using gets()No bounds check; removed from the standard. Use fgets.
Forgetting the null terminatorString functions read past the buffer. Allocate length + 1.
sizeof on an array parameterIt gives the pointer size, not the array size. Pass the length.
Returning address of a localThe stack frame is gone; pointer dangles.
malloc without NULL checkCrash on allocation failure.

Double freeHeap corruption. Set pointer to NULL after free.
realloc assigned directly to the same pointerOn failure the original block leaks. Use a temp.
Modifying a string literalUndefined; use a char array.
Signed integer overflowUndefined; use unsigned or check before the operation.
Comparing signed with unsignedSigned value converts to unsigned; negative becomes huge.
Comparing floats with ==Use a tolerance: fabs(a - b) < eps.
