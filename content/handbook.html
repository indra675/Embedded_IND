Part A: Learning Roadmap and Projects

A1. How to Use This Handbook

  • Work through the stages in order, but only move on when you can pass the "Done when" check of the current stage on real hardware.
  • Type the code yourself, run it on a board, then change it on purpose (different pin, different period) and predict what will happen before running.
  • Read the matching chapter of your MCU reference manual after each program. Find every register you touched and note its reset value.
  • Code in Part B is written for an STM32F401RE or F411RE Nucleo board using CMSIS register names (stm32f4xx.h). The ideas transfer to any MCU: only the register names and addresses change. Part B16 shows the same ideas on AVR.
  • Default clock after reset is the 16 MHz internal oscillator, so no clock configuration is needed for these programs.
  • On Nucleo-F401RE the green LED is PA5, the user button is PC13 (pressed = low), and USART2 (PA2 TX, PA3 RX) goes to the ST-Link virtual COM port.

Part B: Hands-On Programs

All code assumes #include "stm32f4xx.h" and the default 16 MHz clock. Bit position values are explained in comments. Check each register against your MCU reference manual.

B1. Project Setup and Common Helpers

Put these helpers in a shared header; later programs use them.

#include "stm32f4xx.h"
#include <stdint.h>
#include <stdbool.h>
#include <string.h>
#define LED_PIN      5U                         /* PA5  */
#define LED_ON()     (GPIOA->BSRR = (1U << LED_PIN))
#define LED_OFF()    (GPIOA->BSRR = (1U << (LED_PIN + 16U)))
#define LED_TOGGLE() (GPIOA->ODR ^= (1U << LED_PIN))
/* ----- 1 ms timebase using SysTick ----- */
static volatile uint32_t ms_ticks;
void SysTick_Handler(void) { ms_ticks++; }
static inline uint32_t millis(void) { return ms_ticks; }
void delay_ms(uint32_t d) {
    uint32_t start = millis();
    while ((uint32_t)(millis() - start) < d) { }   /* safe across wrap-around */
}
void systick_init(void) {
    SysTick_Config(SystemCoreClock / 1000U);        /* 16 MHz / 1000 = 1 ms */
}
  • BSRR writes are atomic: the lower 16 bits set pins, the upper 16 bits reset pins. No read-modify-write is needed.
  • SystemCoreClock holds the CPU frequency (16000000 after reset). SysTick_Config also enables the SysTick interrupt.

B2. GPIO: Blink LED

Goal: configure a pin as output and toggle it. Concepts: enabling the peripheral clock, MODER fields, ODR vs BSRR.

void led_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;           /* 1. clock for GPIOA        */
    GPIOA->MODER &= ~(3U << (LED_PIN * 2U));       /* 2. clear mode bits        */
    GPIOA->MODER |=  (1U << (LED_PIN * 2U));       /*    01 = general output    */
    /* OTYPER default = push-pull, OSPEEDR default = low speed: fine for an LED */
}
int main(void) {
    systick_init();
    led_init();
    for (;;) {
        LED_TOGGLE();
        delay_ms(500);
    }
}
  • MODER uses two bits per pin: 00 input, 01 output, 10 alternate function, 11 analog.
  • Try: make the LED blink SOS in Morse; change to an external LED on another pin; blink at 5 Hz and verify the period with a logic analyzer.

B3. GPIO: Read a Button (polling)

Goal: LED follows the button. Concepts: input mode, IDR, active-low logic.

void button_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;
    GPIOC->MODER &= ~(3U << (13U * 2U));          /* 00 = input                 */
    /* Nucleo has an external pull-up on PC13. For a plain pin enable one:
       GPIOC->PUPDR |= (1U << (pin * 2U));  (01 = pull-up, 10 = pull-down)      */
}
static inline bool button_pressed(void) {
    return (GPIOC->IDR & (1U << 13U)) == 0U;      /* pressed = low              */
}
int main(void) {
    systick_init(); led_init(); button_init();
    for (;;) {
        if (button_pressed()) LED_ON(); else LED_OFF();
    }
}
  • A floating input reads random values. Always use a pull-up or pull-down (external or internal).
  • Try: toggle the LED on each press (detect the edge, not the level) and see how bouncing causes false toggles. This motivates B5.

B4. SysTick Millisecond Timebase and Non-Blocking Blink

Goal: run two periodic jobs without blocking delays. Concepts: free-running tick, wrap-safe comparison, cooperative scheduling.

typedef struct {
    uint32_t period;
    uint32_t last;
    void (*run)(void);
} Job;
static void job_led(void)  { LED_TOGGLE(); }
static void job_heartbeat(void) { /* e.g. send "alive" over UART */ }
static Job jobs[] = {
    { 500U,  0U, job_led },
    { 2000U, 0U, job_heartbeat },
};
int main(void) {
    systick_init(); led_init();
    for (;;) {
        uint32_t now = millis();
        for (uint32_t i = 0; i < sizeof jobs / sizeof jobs[0]; i++) {
            if ((uint32_t)(now - jobs[i].last) >= jobs[i].period) {
                jobs[i].last += jobs[i].period;      /* keeps long-term accuracy */
                jobs[i].run();
            }
        }
    }
}
  • Using last += period instead of last = now avoids accumulating drift.
  • Each job must be short. A long job delays every other one: that is the limitation of a cooperative scheduler.

B5. External Interrupt (button) with Debounce

Goal: handle the button in an interrupt without bouncing. Concepts: EXTI, SYSCFG routing, NVIC, ISR flag handoff, debounce with time.

static volatile bool button_event = false;
static volatile uint32_t last_press_ms = 0;
void button_irq_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;
    RCC->APB2ENR |= RCC_APB2ENR_SYSCFGEN;               /* needed for EXTI routing */
    GPIOC->MODER &= ~(3U << (13U * 2U));                /* PC13 input              */
    SYSCFG->EXTICR[3] &= ~SYSCFG_EXTICR4_EXTI13;        /* EXTI13 <- port C        */
    SYSCFG->EXTICR[3] |=  SYSCFG_EXTICR4_EXTI13_PC;
    EXTI->IMR  |= EXTI_IMR_MR13;                        /* unmask line 13          */
    EXTI->FTSR |= EXTI_FTSR_TR13;                       /* falling edge = press    */
    NVIC_SetPriority(EXTI15_10_IRQn, 2U);
    NVIC_EnableIRQ(EXTI15_10_IRQn);
}
void EXTI15_10_IRQHandler(void) {
    if (EXTI->PR & EXTI_PR_PR13) {
        EXTI->PR = EXTI_PR_PR13;                        /* write 1 to clear flag   */
        uint32_t now = millis();
        if ((uint32_t)(now - last_press_ms) > 50U) {    /* ignore bounces < 50 ms  */
            last_press_ms = now;
            button_event = true;
        }
    }
}
int main(void) {
    systick_init(); led_init(); button_irq_init();
    for (;;) {
        if (button_event) {
            button_event = false;
            LED_TOGGLE();
        }
    }
}
  • The pending flag is write-1-to-clear. If you forget to clear it, the ISR fires continuously.
  • The ISR only sets a flag; the real work happens in main. This keeps the ISR short.
  • Try: count presses and print them over UART (after B8); add long-press detection using the press and release timestamps.

B6. Timer Interrupt

Goal: toggle the LED exactly once per second from a hardware timer. Concepts: prescaler, auto-reload, update interrupt.

Calculation: timer clock 16 MHz, PSC = 15999 gives 1 kHz (1 ms per tick); ARR = 999 gives 1000 ticks = 1 second.

void tim2_init(void) {
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    TIM2->PSC  = 16000U - 1U;                 /* 16 MHz / 16000 = 1 kHz       */
    TIM2->ARR  = 1000U - 1U;                  /* 1000 ticks = 1 s             */
    TIM2->EGR  = TIM_EGR_UG;                  /* load prescaler/ARR now       */
    TIM2->SR   = 0U;                          /* clear flag caused by UG      */
    TIM2->DIER |= TIM_DIER_UIE;               /* update interrupt enable      */
    NVIC_EnableIRQ(TIM2_IRQn);
    TIM2->CR1  |= TIM_CR1_CEN;                /* start counting               */
}
void TIM2_IRQHandler(void) {
    if (TIM2->SR & TIM_SR_UIF) {
        TIM2->SR &= ~TIM_SR_UIF;              /* clear update flag            */
        LED_TOGGLE();
    }
}
int main(void) {
    led_init(); tim2_init();
    for (;;) { __WFI(); }                     /* sleep until the next interrupt */
}
  • Period = (PSC + 1) x (ARR + 1) / f_clk. Check with a logic analyzer.
  • Try: change the period at runtime from a button press; measure the ISR duration by toggling a second GPIO inside it.

B7. PWM: LED Fade

Goal: fade the on-board LED using PWM. Concepts: alternate function, output compare, duty cycle. PA5 is TIM2 channel 1 (alternate function 1).

void pwm_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    GPIOA->MODER &= ~(3U << (5U * 2U));
    GPIOA->MODER |=  (2U << (5U * 2U));       /* 10 = alternate function       */
    GPIOA->AFR[0] &= ~(0xFU << (5U * 4U));
    GPIOA->AFR[0] |=  (1U   << (5U * 4U));    /* AF1 = TIM2_CH1                */
    TIM2->PSC   = 16U - 1U;                   /* 1 MHz timer clock             */
    TIM2->ARR   = 1000U - 1U;                 /* 1 kHz PWM frequency           */
    TIM2->CCMR1 = (6U << 4) | (1U << 3);      /* OC1M = 110 PWM mode 1, preload */
    TIM2->CCER |= TIM_CCER_CC1E;              /* enable channel 1 output       */
    TIM2->CR1  |= TIM_CR1_ARPE;
    TIM2->EGR   = TIM_EGR_UG;
    TIM2->CR1  |= TIM_CR1_CEN;
}
static inline void pwm_set_duty(uint16_t permille) {   /* 0..1000 */
    TIM2->CCR1 = permille;                     /* duty = CCR1 / (ARR + 1)       */
}
int main(void) {
    systick_init(); pwm_init();
    for (;;) {
        for (uint16_t d = 0; d <= 1000; d += 5) { pwm_set_duty(d); delay_ms(5); }
        for (uint16_t d = 1000; d > 0; d -= 5)  { pwm_set_duty(d); delay_ms(5); }
    }
}
  • Duty cycle = CCR / (ARR + 1). With ARR = 999, CCR = 250 gives 25 percent.
  • For a hobby servo use a 50 Hz period (20 ms) with a pulse of 1 to 2 ms: PSC = 15 (1 MHz), ARR = 19999, CCR = 1000 to 2000.
  • Human eyes see brightness non-linearly: a gamma lookup table makes fades look smoother.

B8. UART: Transmit, Echo and Receive Interrupt

Goal: send text to the PC, echo typed characters, then receive with an interrupt and a ring buffer. Terminal: 115200, 8N1.

Baud calculation (oversampling by 16): USARTDIV = 16,000,000 / (16 x 115200) = 8.6806. Mantissa = 8, fraction = 0.6806 x 16 = 10.89, rounded to 11, so BRR = (8 << 4) | 11 = 0x8B.

void uart2_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;
    RCC->APB1ENR |= RCC_APB1ENR_USART2EN;
    /* PA2 = TX, PA3 = RX, alternate function 7 */
    GPIOA->MODER &= ~((3U << (2U * 2U)) | (3U << (3U * 2U)));
    GPIOA->MODER |=  ((2U << (2U * 2U)) | (2U << (3U * 2U)));
    GPIOA->AFR[0] &= ~((0xFU << (2U * 4U)) | (0xFU << (3U * 4U)));
    GPIOA->AFR[0] |=  ((7U   << (2U * 4U)) | (7U   << (3U * 4U)));
    USART2->BRR = 0x8BU;                                    /* 115200 @ 16 MHz */
    USART2->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
void uart_putc(char ch) {
    while (!(USART2->SR & USART_SR_TXE)) { }                /* wait for empty  */
    USART2->DR = (uint8_t)ch;
}
void uart_puts(const char *s) { while (*s) uart_putc(*s++); }
void uart_put_u32(uint32_t v) {
    char buf[11]; int i = 0;
    if (v == 0U) { uart_putc('0'); return; }
    while (v) { buf[i++] = (char)('0' + v % 10U); v /= 10U; }
    while (i--) uart_putc(buf[i]);
}
/* Polling echo */
int main(void) {
    systick_init(); uart2_init();
    uart_puts("Hello from STM32\r\n");
    for (;;) {
        if (USART2->SR & USART_SR_RXNE) {                   /* byte received   */
            uart_putc((char)USART2->DR);                    /* echo it back    */
        }
    }
}

Receive with interrupt and ring buffer

#define RB_SIZE 64U                                         /* power of two    */
typedef struct {
    uint8_t buf[RB_SIZE];
    volatile uint16_t head, tail;
} RingBuf;
static RingBuf rx;
static int rb_put(RingBuf *rb, uint8_t v) {
    uint16_t next = (uint16_t)((rb->head + 1U) & (RB_SIZE - 1U));
    if (next == rb->tail) return -1;                        /* full  */
    rb->buf[rb->head] = v; rb->head = next; return 0;
}
static int rb_get(RingBuf *rb, uint8_t *v) {
    if (rb->head == rb->tail) return -1;                    /* empty */
    *v = rb->buf[rb->tail];
    rb->tail = (uint16_t)((rb->tail + 1U) & (RB_SIZE - 1U));
    return 0;
}
void uart2_rx_irq_enable(void) {
    USART2->CR1 |= USART_CR1_RXNEIE;                        /* interrupt on RXNE */
    NVIC_SetPriority(USART2_IRQn, 3U);
    NVIC_EnableIRQ(USART2_IRQn);
}
void USART2_IRQHandler(void) {
    if (USART2->SR & USART_SR_RXNE) {
        uint8_t b = (uint8_t)USART2->DR;                    /* reading DR clears RXNE */
        (void)rb_put(&rx, b);                               /* drop byte if full      */
    }
}
  • Reading DR clears the RXNE flag. Overrun errors (ORE) happen if bytes arrive faster than you read them.
  • The ring buffer has one producer (ISR) and one consumer (main), so it needs no lock. One slot is left empty to tell full from empty.
  • For transmit-heavy designs use a TX ring buffer with the TXE interrupt, or DMA.

B9. UART Command Shell

Goal: type commands in a terminal to control the board: led on, led off, adc (after B10), ticks.

static char    line[32];
static uint8_t line_len;
static void handle_command(const char *s) {
    if      (strcmp(s, "led on")  == 0) { LED_ON();  uart_puts("OK\r\n"); }
    else if (strcmp(s, "led off") == 0) { LED_OFF(); uart_puts("OK\r\n"); }
    else if (strcmp(s, "ticks")   == 0) { uart_put_u32(millis()); uart_puts(" ms\r\n"); }
    else if (strcmp(s, "adc")     == 0) { uart_put_u32(adc_read_mv()); uart_puts(" mV\r\n"); }
    else                                  { uart_puts("unknown command\r\n"); }
}
void shell_poll(void) {
    uint8_t c;
    while (rb_get(&rx, &c) == 0) {
        if (c == '\r' || c == '\n') {
            line[line_len] = '\0';
            if (line_len) handle_command(line);
            line_len = 0;
            uart_puts("> ");
        } else if (line_len < sizeof line - 1U) {
            line[line_len++] = (char)c;
            uart_putc((char)c);                             /* local echo */
        }                                                   /* else: ignore overflow */
    }
}
int main(void) {
    systick_init(); led_init(); uart2_init(); uart2_rx_irq_enable();
    uart_puts("Shell ready\r\n> ");
    for (;;) { shell_poll(); }
}
  • Never overflow the line buffer: check the length before every store.
  • Try: add a command table (name, handler function pointer), argument parsing (pwm 250), backspace handling, and help text.

B10. ADC: Read a Potentiometer

Goal: read PA0 (ADC1 channel 0) and convert to millivolts. Wire the potentiometer ends to 3.3 V and GND, and the wiper to PA0.

void adc_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_ADC1EN;
    GPIOA->MODER |= (3U << (0U * 2U));         /* 11 = analog mode for PA0      */
    ADC1->SMPR2 = 7U;                          /* channel 0: longest sampling   */
    ADC1->SQR1  = 0U;                          /* 1 conversion in the sequence  */
    ADC1->SQR3  = 0U;                          /* first conversion = channel 0  */
    ADC1->CR2  |= ADC_CR2_ADON;                /* power on ADC                  */
}
uint16_t adc_read_raw(void) {
    ADC1->CR2 |= ADC_CR2_SWSTART;              /* start conversion              */
    while (!(ADC1->SR & ADC_SR_EOC)) { }       /* wait end of conversion        */
    return (uint16_t)ADC1->DR;                 /* reading DR clears EOC         */
}
uint16_t adc_read_avg(uint8_t n) {             /* simple averaging              */
    uint32_t sum = 0;
    for (uint8_t i = 0; i < n; i++) sum += adc_read_raw();
    return (uint16_t)(sum / n);
}
uint32_t adc_read_mv(void) {
    return ((uint32_t)adc_read_avg(16) * 3300U) / 4095U;   /* 12-bit, Vref 3.3 V */
}
  • 12-bit ADC: 4096 levels, one step is about 0.8 mV at 3.3 V.
  • Use the largest sampling time for high-impedance sources such as a potentiometer. Add a small capacitor on the input to reduce noise.
  • Try: map the ADC value to PWM duty (B7) to make a dimmer; implement a moving-average filter (Part C3); log values over UART.

B11. SPI: Hardware and Software

Hardware SPI1 master (PA5 SCK, PA6 MISO, PA7 MOSI, alternate function 5; chip select on PB6 as a normal GPIO). On the Nucleo, PA5 is also the LED, so the LED will flicker: use SPI2 pins on PB13/PB14/PB15 (APB1) if that bothers you.

void spi1_init(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN | RCC_AHB1ENR_GPIOBEN;
    RCC->APB2ENR |= RCC_APB2ENR_SPI1EN;
    /* PA5, PA6, PA7 -> alternate function 5 */
    GPIOA->MODER &= ~((3U << 10) | (3U << 12) | (3U << 14));
    GPIOA->MODER |=  ((2U << 10) | (2U << 12) | (2U << 14));
    GPIOA->AFR[0] &= ~((0xFU << 20) | (0xFU << 24) | (0xFU << 28));
    GPIOA->AFR[0] |=  ((5U   << 20) | (5U   << 24) | (5U   << 28));
    /* PB6 = chip select, output, idle high */
    GPIOB->MODER &= ~(3U << 12);  GPIOB->MODER |= (1U << 12);
    GPIOB->BSRR = (1U << 6);
    /* Master, software slave management, baud = fPCLK/16 = 1 MHz, mode 0 */
    SPI1->CR1 = SPI_CR1_MSTR | SPI_CR1_SSM | SPI_CR1_SSI | (3U << 3);
    SPI1->CR1 |= SPI_CR1_SPE;                                 /* enable last */
}
uint8_t spi1_xfer(uint8_t tx) {
    while (!(SPI1->SR & SPI_SR_TXE)) { }
    SPI1->DR = tx;
    while (!(SPI1->SR & SPI_SR_RXNE)) { }
    return (uint8_t)SPI1->DR;
}
#define CS_LOW()   (GPIOB->BSRR = (1U << (6U + 16U)))
#define CS_HIGH()  (GPIOB->BSRR = (1U << 6U))
/* Example: read the JEDEC ID of an SPI flash (command 0x9F) */
void flash_read_id(uint8_t id[3]) {
    CS_LOW();
    (void)spi1_xfer(0x9F);
    id[0] = spi1_xfer(0xFF);
    id[1] = spi1_xfer(0xFF);
    id[2] = spi1_xfer(0xFF);
    while (SPI1->SR & SPI_SR_BSY) { }                         /* wait until idle */
    CS_HIGH();
}

Software (bit-banged) SPI, mode 0 works on any MCU; replace the macros with your GPIO operations.

/* Provide: SCK_HIGH/LOW, MOSI_HIGH/LOW, MISO_READ, spi_delay() */
uint8_t soft_spi_xfer(uint8_t tx) {
    uint8_t rx = 0;
    for (int i = 7; i >= 0; i--) {                 /* MSB first                    */
        if (tx & (1U << i)) MOSI_HIGH(); else MOSI_LOW();
        spi_delay();
        SCK_HIGH();                                /* rising edge: slave samples   */
        rx = (uint8_t)((rx << 1) | (MISO_READ() ? 1U : 0U));
        spi_delay();
        SCK_LOW();                                 /* falling edge: next bit shifts */
    }
    return rx;
}
  • SPI is full duplex: every byte sent also receives a byte. To read, send a dummy byte (0xFF).
  • Mode (CPOL, CPHA) must match the device datasheet. Check clock polarity and sampling edge on a logic analyzer.
  • Always keep chip select high when idle and low only during a transaction.

B12. I2C: Software (Bit-Banged) Driver and Sensor Read

A bit-banged I2C driver is a great way to understand the protocol and works on any MCU. Use two GPIO pins configured as open-drain with external 4.7 kOhm pull-ups to 3.3 V. Releasing a line means setting it high (the pull-up raises it); driving low pulls it down.

/* Provide these for your pins (open-drain outputs, input readable):
   SDA_HIGH() SDA_LOW() SDA_READ()  SCL_HIGH() SCL_LOW()  i2c_delay()  */
static void i2c_start(void) {
    SDA_HIGH(); SCL_HIGH(); i2c_delay();
    SDA_LOW();  i2c_delay();                  /* SDA falls while SCL high = START */
    SCL_LOW();
}
static void i2c_stop(void) {
    SDA_LOW();  i2c_delay();
    SCL_HIGH(); i2c_delay();
    SDA_HIGH(); i2c_delay();                  /* SDA rises while SCL high = STOP  */
}
static bool i2c_write_byte(uint8_t b) {       /* returns true if slave ACKed      */
    for (int i = 7; i >= 0; i--) {
        if (b & (1U << i)) SDA_HIGH(); else SDA_LOW();
        i2c_delay(); SCL_HIGH(); i2c_delay(); SCL_LOW();
    }
    SDA_HIGH();                               /* release SDA for the ACK bit      */
    i2c_delay(); SCL_HIGH(); i2c_delay();
    bool ack = (SDA_READ() == 0);             /* slave pulls SDA low to ACK       */
    SCL_LOW();
    return ack;
}
static uint8_t i2c_read_byte(bool ack) {
    uint8_t v = 0;
    SDA_HIGH();                               /* release SDA so slave can drive   */
    for (int i = 0; i < 8; i++) {
        i2c_delay(); SCL_HIGH(); i2c_delay();
        v = (uint8_t)((v << 1) | (SDA_READ() ? 1U : 0U));
        SCL_LOW();
    }
    if (ack) SDA_LOW(); else SDA_HIGH();      /* ACK to continue, NACK to end     */
    i2c_delay(); SCL_HIGH(); i2c_delay(); SCL_LOW();
    SDA_HIGH();
    return v;
}
/* Read one register: START, addr+W, reg, repeated START, addr+R, data, NACK, STOP */
bool i2c_read_reg(uint8_t addr7, uint8_t reg, uint8_t *out) {
    i2c_start();
    if (!i2c_write_byte((uint8_t)(addr7 << 1)))      { i2c_stop(); return false; }
    if (!i2c_write_byte(reg))                        { i2c_stop(); return false; }
    i2c_start();                                     /* repeated start */
    if (!i2c_write_byte((uint8_t)((addr7 << 1) | 1U))) { i2c_stop(); return false; }
    *out = i2c_read_byte(false);
    i2c_stop();
    return true;
}
/* Sensor check: MPU6050 at 7-bit address 0x68, WHO_AM_I register 0x75 returns 0x68 */
bool mpu_present(void) {
    uint8_t id = 0;
    return i2c_read_reg(0x68, 0x75, &id) && id == 0x68;
}
  • Frame order: START, 7-bit address plus R/W bit, ACK, data bytes with ACKs, STOP. The 7-bit address is shifted left by one before adding the R/W bit; many datasheets quote the 8-bit form, so check which one you are using.
  • If the bus hangs with SDA stuck low, toggle SCL up to nine times and send a STOP to release the slave.
  • Hardware I2C steps (instead of bit-banging): enable the GPIO and I2C clocks, set pins to alternate function open-drain with pull-ups, configure the peripheral clock and clock control registers (CCR/TRISE), enable the peripheral, then follow the START, address, data, STOP flag sequence. Many people use the vendor HAL for this after understanding the bit-banged version.
  • Always verify the first transaction with a logic analyzer protocol decoder.

B13. Watchdog and Low-Power Sleep

Independent watchdog (IWDG)

void iwdg_init(void) {
    IWDG->KR  = 0x5555U;        /* unlock PR and RLR                            */
    IWDG->PR  = 3U;             /* prescaler /32: LSI (about 32 kHz) -> 1 kHz   */

}

int main(void) {

    }
}

B14. FreeRTOS: Tasks, Queue from ISR, Mutex

#include "FreeRTOS.h"
#include "task.h"
#include "queue.h"
#include "semphr.h"
static QueueHandle_t     rx_queue;
static SemaphoreHandle_t uart_mutex;
static void uart_print_safe(const char *s) {
    xSemaphoreTake(uart_mutex, portMAX_DELAY);       /* one task prints at a time */
    uart_puts(s);
    xSemaphoreGive(uart_mutex);
}
static void task_blink(void *arg) {
    (void)arg;
    for (;;) {
        LED_TOGGLE();
        vTaskDelay(pdMS_TO_TICKS(500));              /* blocks, lets others run   */
    }
}
static void task_rx(void *arg) {
    (void)arg;
    uint8_t b;
    for (;;) {
        if (xQueueReceive(rx_queue, &b, portMAX_DELAY) == pdPASS) {
            uart_print_safe("got a byte\r\n");
        }
    }
}
void USART2_IRQHandler(void) {
    BaseType_t woken = pdFALSE;
    if (USART2->SR & USART_SR_RXNE) {
        uint8_t b = (uint8_t)USART2->DR;
        xQueueSendFromISR(rx_queue, &b, &woken);     /* ISR-safe API only         */
    }
    portYIELD_FROM_ISR(woken);                       /* switch now if needed      */
}
int main(void) {
    __disable_irq();                                 /* stay quiet until the scheduler starts */
    NVIC_SetPriorityGrouping(0U);                    /* FreeRTOS wants all priority bits as preemption bits */
    led_init(); uart2_init();
    rx_queue   = xQueueCreate(32, sizeof(uint8_t)); /* create the queue BEFORE the RX interrupt can fire */
    uart_mutex = xSemaphoreCreateMutex();
    uart2_rx_irq_enable();
    NVIC_SetPriority(USART2_IRQn, 6U);               /* B8 used 3: too urgent for FromISR calls; use a value >= configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY (5 in the CubeMX default) */
    xTaskCreate(task_blink, "blink", 128, NULL, 1, NULL);
    xTaskCreate(task_rx,    "rx",    256, NULL, 2, NULL);   /* higher priority    */
    vTaskStartScheduler();                           /* never returns             */
    for (;;) { }
}
  • Interrupts that call FreeRTOS "FromISR" functions must have a priority number that is not more urgent than configMAX_SYSCALL_INTERRUPT_PRIORITY (on Cortex-M a larger number is less urgent). The USART2 priority of 3 used in B8 is too urgent for FreeRTOS, so raise its number as shown above. Mistakes here cause random crashes.
  • Size each task stack with care (words, not bytes in FreeRTOS). Enable stack overflow checking during development.
  • Use queues to pass data, mutexes to protect shared resources, and binary semaphores to signal events from ISRs.
  • Try: add a third task that reads the ADC every 100 ms and sends results through a queue to a printing task; then deliberately create priority inversion and see how a mutex with priority inheritance helps.

B15. Mini Project: Sensor Logger with State Machine

Combine everything: read the ADC every second, average it, log it over UART, and allow commands. A state machine controls the mode.

typedef enum { ST_IDLE, ST_LOGGING, ST_ERROR } State;
static State state = ST_IDLE;
static uint32_t last_sample_ms;
static void on_command(const char *cmd) {
    if      (strcmp(cmd, "start") == 0 && state == ST_IDLE)    state = ST_LOGGING;
    else if (strcmp(cmd, "stop")  == 0 && state == ST_LOGGING) state = ST_IDLE;
    else if (strcmp(cmd, "reset") == 0)                        state = ST_IDLE;
}
int main(void) {
    systick_init(); led_init(); uart2_init(); uart2_rx_irq_enable(); adc_init();
    iwdg_init();
    for (;;) {
        shell_poll();                                         /* parse commands    */
        switch (state) {
        case ST_IDLE:
            LED_OFF();
            break;
        case ST_LOGGING:
            if ((uint32_t)(millis() - last_sample_ms) >= 1000U) {
                last_sample_ms += 1000U;
                uint32_t mv = adc_read_mv();
                uart_put_u32(millis()); uart_puts(","); uart_put_u32(mv); uart_puts("\r\n");
                LED_TOGGLE();
                if (mv > 3200U) state = ST_ERROR;             /* out-of-range input */
            }
            break;
        case ST_ERROR:
            LED_ON();                                         /* solid LED = error  */
            break;
        }
        iwdg_kick();
    }
}
  • Extend: store the last 60 samples in a circular buffer and add a dump command; compute min, max and average; add a version string and a build timestamp; place calibration constants in a Flash page.

uint32_t swap_odd_even(uint32_t x) {

int ctz(uint32_t x) {

    int n = 0;

5. Round up to the next power of two

uint32_t next_pow2(uint32_t x) {
    if (x == 0) return 1;
    x--;
    x |= x >> 1; x |= x >> 2; x |= x >> 4; x |= x >> 8; x |= x >> 16;
    return x + 1;
}

uint32_t missing(const uint32_t *a, uint32_t n) {   /* n elements, values 1..n+1 */

    for (uint32_t i = 1; i <= n + 1; i++) x ^= i;
    for (uint32_t i = 0; i < n; i++)      x ^= a[i];

}

uint32_t rev32(uint32_t x) {

5. Fixed-size block memory pool (no malloc)

#define BLOCK_SIZE   32U             /* must be >= sizeof(void *) */
#define BLOCK_COUNT  8U
static uint8_t pool[BLOCK_COUNT][BLOCK_SIZE] __attribute__((aligned(4)));
static void *free_list;
void pool_init(void) {
    free_list = NULL;
    for (uint32_t i = BLOCK_COUNT; i--; ) {
        *(void **)pool[i] = free_list;       /* store next pointer in the block */
        free_list = pool[i];
    }
}
void *pool_alloc(void) {
    void *p = free_list;
    if (p) free_list = *(void **)p;
    return p;                                /* NULL when exhausted             */
}
void pool_free(void *p) {
    *(void **)p = free_list;
    free_list = p;
}

Allocation and free take constant time and cause no fragmentation. If used from several contexts, wrap alloc and free in a critical section.

6. Implement itoa

char *my_itoa(int32_t v, char *buf) {
    char tmp[12]; int i = 0, n = 0;
    uint32_t u = (v < 0) ? (uint32_t)(-(int64_t)v) : (uint32_t)v;
    if (u == 0) tmp[i++] = '0';
    while (u) { tmp[i++] = (char)('0' + u % 10U); u /= 10U; }
    if (v < 0) buf[n++] = '-';
    while (i--) buf[n++] = tmp[i];
    buf[n] = '\0';
    return buf;
}

7. Reverse a linked list and detect a cycle

typedef struct Node { int v; struct Node *next; } Node;
Node *reverse(Node *h) {
    Node *prev = NULL;
    while (h) { Node *nx = h->next; h->next = prev; prev = h; h = nx; }
    return prev;
}
bool has_cycle(Node *h) {
    Node *s = h, *f = h;
    while (f && f->next) {
        s = s->next; f = f->next->next;
        if (s == f) return true;
    }
    return false;
}

C3. Embedded Design Problems

1. Moving average filter

#define N 8U
typedef struct { uint16_t buf[N]; uint32_t sum; uint8_t idx, count; } MovAvg;
uint16_t movavg_update(MovAvg *m, uint16_t x) {
    m->sum -= m->buf[m->idx];                 /* remove oldest sample             */
    m->buf[m->idx] = x;
    m->sum += x;
    m->idx = (uint8_t)((m->idx + 1U) % N);
    if (m->count < N) m->count++;
    return (uint16_t)(m->sum / m->count);
}

2. Software timers with callbacks

typedef struct {
    uint32_t period, last;
    bool     repeat, active;
    void   (*cb)(void);
} SwTimer;
void swtimer_poll(SwTimer *t, uint32_t now) {
    if (!t->active) return;
    if ((uint32_t)(now - t->last) >= t->period) {
        t->last += t->period;
        if (!t->repeat) t->active = false;
        t->cb();
    }
}

3. Parse a UART frame with a state machine

Frame format: start byte 0xAA, length byte (payload size), payload bytes, checksum (XOR of length and all payload bytes).

typedef enum { S_START, S_LEN, S_DATA, S_CHK } PState;
typedef struct {
    PState  st;
    uint8_t len, idx, chk;
    uint8_t data[32];
} Parser;
/* returns true when a complete, valid frame is in p->data[0..len-1] */
bool parser_feed(Parser *p, uint8_t b) {
    switch (p->st) {
    case S_START:
        if (b == 0xAAU) p->st = S_LEN;
        break;
    case S_LEN:
        /* reject bad length */
        if (b == 0U || b > sizeof p->data) { p->st = S_START; break; }
        p->len = b; p->idx = 0; p->chk = b; p->st = S_DATA;
        break;
    case S_DATA:
        p->data[p->idx++] = b;
        p->chk ^= b;
        if (p->idx == p->len) p->st = S_CHK;
        break;
    case S_CHK:
        p->st = S_START;
        return (b == p->chk);
    }
    return false;
}

Points interviewers like: resynchronize on errors, bound-check the length, do not block, and process one byte at a time so it works from an ISR or a DMA buffer.

4. Switch debounce with a shift register

/* call every 1 ms with the raw pin state */
bool debounce(bool raw) {
    static uint8_t hist = 0;
    static bool state = false;
    hist = (uint8_t)((hist << 1) | (raw ? 1U : 0U));
    if (hist == 0xFFU) state = true;          /* 8 consecutive ones  */
    else if (hist == 0x00U) state = false;    /* 8 consecutive zeros */
    return state;
}

static volatile uint32_t counter;             /* incremented in an ISR            */

6. Average ADC samples without overflow

uint16_t avg_u16(const uint16_t *a, uint32_t n) {
    uint32_t sum = 0;                         /* 32-bit accumulator avoids overflow */
    for (uint32_t i = 0; i < n; i++) sum += a[i];

}

7. CRC-16 (CCITT, polynomial 0x1021)

uint16_t crc16_ccitt(const uint8_t *d, size_t n) {
    uint16_t crc = 0xFFFFU;
    while (n--) {
        crc ^= (uint16_t)(*d++) << 8;
        for (int i = 0; i < 8; i++)
            crc = (crc & 0x8000U) ? (uint16_t)((crc << 1) ^ 0x1021U) : (uint16_t)(crc << 1);
    }
    return crc;
}

C5. How to Approach a Coding Round

  • Restate the problem and confirm input ranges, types, and whether it runs in an ISR, on a tiny MCU, or with an OS.
  • Ask about constraints: no malloc, limited RAM, no floating point, thread safety.
  • State your plan before coding. Write clean C with fixed-width types and clear names.
  • Handle edge cases out loud: zero length, NULL pointers, buffer full or empty, wrap-around, overflow.
  • Test with a small example by hand, including at least one edge case.
  • Explain complexity and memory use. Mention how you would test it on hardware (logic analyzer, unit tests on PC).
  • If you get stuck, talk through what you know and try a simpler version first. Interviewers value reasoning as much as the final answer.
  • Be ready to explain every line of anything on your resume. Bring one project you can explain end to end: hardware, firmware architecture, a bug you debugged, and what you learned.
